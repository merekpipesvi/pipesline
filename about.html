At work, I've built two different systems. Both are full IaC setups in Azure.

01 · graph rag · prediction

Time entry prediction

It pulls data from a number of integrations and stores it on a synced schedule. It then makes predictions on that data using a graph RAG system to create time entries for billable and non-billable hours against jobs.

A time entry has a lot of fields (job, task, hours, and more) that it needs to accurately guess, so it uses both heuristics and classification. It falls through a tiered system, first to last:

  1. history for the client learned behaviour
  2. history of teammates
  3. full-text search
  4. vector search
  5. LLMs
  6. …and more
